# Changelog

All notable changes to this project are documented here.

## 0.1.0 - 2026-09-13

### Added

- SQL queries with a safely substituted dataset name and explicit time range.
- Instant and range PromQL queries for Parseable Cloud and Enterprise.
- JSON event ingestion using a separate ingestion endpoint.
- API key authentication and optional multi-tenant routing.
- n8n AI tool support.
